## Цели, задачи и исходные данные

**Цели:**
<!-- - Разработка программы, генерирующей код на языке Haskell на основе кода на языке C. -->
- Сопоставление двух парадигм програм мирования за счет предоставления двух простых программ, выполняющих одно и то же, но написанных на разных языках с разным подходом.

В процессе выполнения работы требуется решить следующие задачи:

Исходными данными для проведения работы является техническое задание, одобренное преподавателем. Оно содержит цели, задачи, этапы проектирования и требования к каждому этапу. Правильно составленный документ станет гарантом успешной эксплуатации проекта.

**Разработка проекта**

Разработка проекта включает в себя выполнение всех запланированных этапов проектирования, соблюдение всех сроков и требований к системе. Модификация календарного плана допустима. 

**Отчетная документация**

Отчетная документация по окончании всех этапов проектирования, составление документа "Руководство пользователя".

## Основные требования к выполнению работы

**Разрабатываемый программный комплекс предназначен** для изучения другого подхода программирования путем сопоставления с привычным для всех в данной сфере подходом.

**Состав разрабатываемого программного комплекса** включает в себя несколько модулей. Модули можно разделить на две группы: модули, предназначенные для генерации кода на языке Haskell из кода на языке C; и модули, предназначенные для оценки сложности алгоритма функции: это дополнительная возможность.

**Программное обеспечение должно обеспечить** следующие технические характеристики по назначению:
1. Надежность; способность программного обеспечения поддерживать нагрузку.
2. Долгосрочность; возможность поддерживать функционал продукта после эксплуатации.
3. Кроссплатформенность; возможность использования программного обеспечения на всех операционных системах.

**Функциональные требования**

1. Чтение и запись файлов.
2. Обработка информации математическими функциями.
3. Взаимодействие с пользователем через консоль.
4. Логирование действий пользователя.
5. Обработка ошибок.

**При разработке математического, программного и информационного обеспечения** должны, преимущественно, использоваться типовые и стандартные средства, существующие библиотечные решения.
